# Real Estate Rental & Tenant Management System
Python · Flask · HTML/CSS/JS · Supabase (PostgreSQL + Auth + Storage)

## الجديد في النسخة دي (v4)
- **نوعين لوجين بس**: Manager و Tenant. اتشال Customer وزرار **Create account** نهائيًا.
- **المدير**: إيميل وباسورد ثابتين من `.env` (`MANAGER_EMAIL` / `MANAGER_PASSWORD`) والحساب بيتعمل أوتوماتيك أول ما تشغّل السيرفر. أي إيميل تاني مينفعش يدخل كمدير. الوحيد اللي يقدر يعمله هو **Forgot password** (لينك على إيميل المدير، صالح 30 دقيقة ولمرة واحدة).
- **المستأجر**: المدير هو اللي يعمله الحساب. أول ما المدير يضغط **Confirm Payment** على طلب الحجز، النظام بيعمل حساب للمستأجر ويبعت **الباسورد على الإيميل اللي حجز بيه**. كمان من صفحة Tenants: **Send login details** أو **Reset password & email**.
- المستأجر يقدر يغيّر الباسورد من القايمة (**Change password**).
- **داشبورد المدير جديد**: sidebar، كروت مؤشرات (الإيرادات، المتأخرات، الإشغال، المستأجرين)، رسم إيرادات ٦ شهور، دونات لحالة العقارات، دفعات تستنى المراجعة، شكاوى مفتوحة، عقود قربت تخلص، وآخر طلبات الحجز. وكل صفحات المدير بقت بنفس الشكل.
- **الصور**: كل صورة في الـ seed بتتستخدم مرة واحدة بس (٣٢ صورة مختلفة)، ومفيش صورة من صور الـ hero/اللوجين بتتكرر في العقارات.

## التشغيل
1. **الباكدجات**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate            # Windows   (Mac/Linux: source .venv/bin/activate)
   pip install -r requirements.txt
   ```
2. **Supabase → SQL Editor** شغّل بالترتيب:
   1. `schema.sql`  (آمن حتى لو كنت شغّلت النسخة القديمة — الجزء الأخير v4 بيمسح حسابات customer القديمة)
   2. `seed.sql`    (بيانات تجريبية: 4 مباني، 12 عقار، 32 صورة مختلفة، مستأجر تجريبي)
3. **Supabase → Authentication → Providers → Email**: أوقف **Confirm email** أثناء التجربة
   (لو سبته مفعّل، الحساب بيتعمل بس لازم يأكد من الإيميل قبل أول لوجين).
4. **المفاتيح والإيميل**: انسخ `.env.example` إلى `.env` واملأه:
   - `SUPABASE_URL` + `SUPABASE_PUBLISHABLE_KEY` + **`SUPABASE_SERVICE_KEY`** (سرّي، ما ترفعوش على GitHub)
   - `MANAGER_EMAIL` + `MANAGER_PASSWORD` (حساب المدير الثابت)
   - إعدادات `SMTP_*` لإرسال الإيميلات. مع Gmail: فعّل 2-Step Verification وبعدين اعمل **App password** وحطه في `SMTP_PASSWORD`.
   - لو `SMTP` مش مظبوط، النظام مش هيقع: بيعرض للمدير بيانات دخول المستأجر في رسالة عشان يبعتها بنفسه، ولينك reset الباسورد بيتطبع في الـ terminal.
5. `python app.py` ثم افتح http://127.0.0.1:5000

## حسابات التجربة
| النوع | إزاي |
|---|---|
| Manager | الإيميل والباسورد اللي كتبتهم في `.env` عند `/login/manager` |
| Tenant | من المدير: **Tenants ← Send login details** للمستأجر التجريبي `john.smith@example.com` (الباسورد بيتبعت على إيميله، أو بيظهر للمدير لو الـ SMTP مش متظبط). أي حجز جديد: ارفع إيصال وبعدين المدير يعمل Confirm |

## الصور (حقيقية)
- كل عقار عنده معرض صور حقيقية (٣ إلى ٧ صور حسب النوع): الصالة، غرفة النوم، المطبخ، الحمام، المبنى من برّه، وللفيلا الحديقة والمسبح.
- الصور من **Unsplash** (ترخيص مجاني للاستخدام التجاري) وبتتحمّل من الإنترنت مباشرة، فلازم الجهاز يكون عليه نت. لو صورة ما اتحمّلتش بتظهر صورة بديلة بدل ما الصفحة تبوظ.
- دي صور توضيحية تمثّل نوع الوحدة، **مش صور شققك الفعلية**. لما تصوّر شققك: **Manager ← Properties ← Manage ← Add photos** (رفع كذا صورة مرة واحدة من الموبايل)، وبعدين احذف الصور الجاهزة. صورك بتتخزن في bucket `property-images` وبتظهر فورًا.
- لو شغّلت `seed.sql` من النسخة السابقة، هو بيمسح الرسومات القديمة ويحط الصور الحقيقية مكانها.
- إيصالات التحويل بتتخزن في bucket **خاص** `receipts`، ولا يفتحها إلا المدير أو صاحبها.

## التصميم
ألوان طبيعية: كريمي دافي، أخضر غابات، تراكوتا، وأزرق حجري. عناوين Fraunces ونص Inter (من Google Fonts، ولو مفيش نت بيستخدم خطوط الجهاز).
الألوان كلها متغيّرات في أول `static/css/style.css` (`:root`) لو عايز تغيّرها.

## الأمان (باختصار)
- كل الجداول عليها RLS مفعّل بدون policies: المفتاح العام وحده ما يقدرش يقرا/يكتب أي حاجة، والسيرفر بس (service key) هو اللي بيوصل للبيانات.
- كل صفحة محمية بـ `role_required`، والمستأجر يشوف شكاواه وإيصالاته بس.
- مفيش تسجيل عام: الحسابات بيعملها المدير بس. الباسوردات بتتخزن مشفّرة عند Supabase Auth.
- باسورد المدير الأولي موجود في `.env` بس عشان إنشاء الحساب أول مرة. بعد ما تعمل Reset، غيّره أو امسحه من `.env`.

## الهيكل
